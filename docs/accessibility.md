# Accesibilidad

- Combina color con forma, etiqueta, anillo o símbolo. Describe los símbolos en el diagrama.
- Comprueba contraste mínimo de 4,5:1 para texto del estudio y 3:1 para marcas funcionales respecto al fondo adyacente. Verifica visibilidad a 960×540.
- Entrega una alternativa textual ordenada para cada video. Si existe narración, incluye captions sincronizados y revisados.
- Si la pieza es interactiva en la web, respeta `prefers-reduced-motion` y ofrece los mismos estados con cambios inmediatos o fundidos breves. Conserva navegación por teclado y foco visible.
- Revisa pausas, ritmo y destellos al reproducir completo.
